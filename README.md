# Anthony Giuggio — personal website

One-page portfolio site (Home, About, Projects, Résumé, Contact) for RESECON 490AI.

- **Open locally:** double-click `index.html`.
- **Publish:** upload everything in this folder (not the folder itself) to the GitHub repository `USERNAME.github.io`, so `index.html` sits at the top.
- **Files:** `index.html` (content), `styles.css` (look; colors at the top), `photo.png` (headshot).
- **Placeholders:** search for `[PLACEHOLDER]` to find everything still to fill in.
